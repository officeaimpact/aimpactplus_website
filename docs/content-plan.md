# Контент-план: SEO + LLM-цитирование

Цель: войти в топ-выдачи по запросам «внедрение ИИ в туризм», «ИИ-турменеджер»,
«ИИ для турагентства», «ИИ для туроператора», «ИИ для отеля» и стать
цитируемым источником в LLM (Яндекс GPT, GigaChat, ChatGPT, Perplexity).

Все материалы — на русском языке, основная терминология — **ИИ**
(собственные названия «Навылет! AI», «AIMPACT+» оставляем). Каждый
материал — это самостоятельная посадочная для SEO/AEO. Структура: H1,
короткое введение в первом абзаце, H2 на каждый под-вопрос, FAQ-блок и
внутренние ссылки. Дублируем FAQ в `FAQPage` JSON-LD.

---

## Принципы

1. **Один материал = один кластер запросов**, а не «обо всём».
2. **TL;DR в первом абзаце** на 2–3 предложения — для AEO и LLM-цитат.
3. **H2 в формате вопроса/утверждения** — LLM любят такие заголовки.
4. **Списки и нумерация** — для citation-friendly выдачи.
5. **FAQ в конце** — обязательный JSON-LD `FAQPage`.
6. **Перелинковка** — каждый материал ссылается минимум на:
   - 1 услугу (`/services/*`)
   - 1 сегмент-решение (`/solutions/*`)
   - 1 кейс (`/cases/*`)
   - 1 смежный материал блога/гайда
7. **Дата обновления** — указываем явно и в JSON-LD, и в UI (раз в 6 месяцев
   ревизия + бамп `dateModified`).
8. **Авторство** — все материалы подписаны от ИИМПАКТ ПЛЮС / Лукиана
   Силагадзе как эксперта по ИИ в туризме при ТПП РФ.

## Технический чек-лист на каждый материал

- [ ] Уникальный `<title>` 50–60 символов с ключом
- [ ] Уникальный `<meta description>` 150–160 символов
- [ ] H1 совпадает с темой (1 шт. на страницу)
- [ ] TL;DR в первом абзаце (2–3 предложения)
- [ ] H2 с вопросной формулировкой
- [ ] Минимум 5 внутренних ссылок
- [ ] FAQ-блок ≥ 5 вопросов
- [ ] `FAQPage` JSON-LD
- [ ] `Article` JSON-LD c `datePublished`, `dateModified`, `author`,
  `publisher`, `image`
- [ ] Хлебные крошки + `BreadcrumbList` JSON-LD
- [ ] OG-изображение 1200×630 с темой материала
- [ ] Добавлен в `sitemap.ts` и `llms-full.txt`
- [ ] Карточка попадает на `/blog` или `/guides`
- [ ] Ревизия через 6 месяцев — обновить `updatedISO`
