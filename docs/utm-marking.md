# UTM-маркировка ссылок для ии-туризм.рф

Все внешние ссылки на сайт маркируем UTM-метками — иначе Яндекс.Метрика
покажет «прямые заходы» вместо реального источника, и нельзя будет
считать конверсию по каналам.

Метки автоматически попадают в форму заявки через `getTrackingMeta()` в
`src/lib/analytics.ts` и фиксируются в каждой сделке.

---

## Базовый формат

```
https://ии-туризм.рф/{путь}?utm_source={где}&utm_medium={формат}&utm_campaign={кампания}&utm_content={конкретная-ссылка}
```

Все значения — латиницей, в нижнем регистре, без пробелов
(пробел = дефис или подчёркивание). Так Метрика их корректно сгруппирует.

---

## Справочник параметров

### `utm_source` — где разместили ссылку

| Значение         | Куда подходит                                |
|------------------|----------------------------------------------|
| `telegram`       | Telegram-канал «Навылет!», личные ЛС, чаты   |
| `vk`             | ВКонтакте (паблик, личные сообщения)         |
| `email`          | Email-рассылки                                |
| `instagram`      | Instagram (посты, сторис, директ)             |
| `linkedin`       | LinkedIn (посты, личные сообщения)            |
| `youtube`        | YouTube (видео, описание, шортсы)             |
| `partner_rst`    | Сайт РСТ, рассылки РСТ                        |
| `partner_tpprf`  | Сайт/материалы ТПП РФ                         |
| `partner_navilet`| Сайт navilet.ru                               |
| `yandex_direct`  | Яндекс.Директ (рекламные кампании)            |
| `google_ads`     | Google Ads                                    |
| `vc`             | VC.ru, статьи на VC                           |
| `habr`           | Habr.com                                      |
| `business_card`  | QR-код визитки или презентации                |

### `utm_medium` — формат размещения

| Значение     | Когда использовать                          |
|--------------|---------------------------------------------|
| `social`     | Бесплатные посты в соцсетях                 |
| `email`      | Email-рассылка                              |
| `cpc`        | Платная реклама с оплатой за клик            |
| `referral`   | Ссылки на сайтах партнёров                  |
| `qr`         | QR-код в офлайне                            |
| `messenger`  | Личные сообщения (1-к-1 ЛС, чаты)           |
| `display`    | Баннерная реклама                            |
| `video`      | Описание под видео                          |

### `utm_campaign` — название кампании

Это рабочее имя — используется только для аналитики, видишь только ты.
Формат: `{тема}-{месяц}` или `{кейс}-{год}`.

Примеры:
- `launch-may-2026` — общая кампания запуска
- `navilet-promo-q2-2026` — продвижение продукта Навылет! AI
- `tpp-congress-2026` — материалы конгресса ТПП
- `blog-7scenariev` — продвижение статьи «7 сценариев»

### `utm_content` — конкретная ссылка в материале

Если в одном посте две разные ссылки на сайт — используй разный
`utm_content`, чтобы понять, какая работает лучше.

Примеры:
- `header-cta` — кнопка в шапке поста
- `text-link-1` — первая ссылка в тексте
- `footer-cta` — финальная кнопка
- `image-card` — кликабельный баннер
- `qr-code-screen` — QR с экрана

## Готовые шаблоны под наши каналы

### Telegram-канал «Навылет! AI»

Пост со ссылкой на блог-статью:

```
https://ии-туризм.рф/blog/ii-dlya-turagentstva-7-scenariev?utm_source=telegram&utm_medium=social&utm_campaign=blog-7scenariev&utm_content=post-{дата}
```

CTA-кнопка «Запросить демо» внизу поста:

```
https://ии-туризм.рф/contact?intent=Запросить%20демо&utm_source=telegram&utm_medium=social&utm_campaign=launch-may-2026&utm_content=cta-button
```

### ВКонтакте (паблик / личные сообщения)

```
https://ии-туризм.рф/?utm_source=vk&utm_medium=social&utm_campaign=launch-may-2026&utm_content=post-{дата}
```

### Email-рассылка (Web3Forms / SendPulse / Mailchimp)

```
https://ии-туризм.рф/navilet-ai?utm_source=email&utm_medium=email&utm_campaign=newsletter-{месяц}-2026&utm_content=hero-button
```

Несколько кнопок в одном письме — меняй только `utm_content`:
- `utm_content=hero-button` — главная кнопка вверху
- `utm_content=feature-1` — ссылка из блока «возможности»
- `utm_content=case-mgp` — ссылка на кейс МГП
- `utm_content=footer-cta` — кнопка внизу

### Партнёры (РСТ, ТПП РФ, navilet.ru)

```
https://ии-туризм.рф/?utm_source=partner_rst&utm_medium=referral&utm_campaign=long-term-partnership&utm_content=members-page
```

### Реклама в Яндекс.Директе

```
https://ии-туризм.рф/services/ai-apps-ux?utm_source=yandex_direct&utm_medium=cpc&utm_campaign=ii-dlya-turagenstva&utm_content={creative_id}
```

В Директе есть переменные через `{}` — `{creative_id}`, `{ad_id}`, `{keyword}`. Они подставляются автоматически.

```
https://ии-туризм.рф/?utm_source=business_card&utm_medium=qr&utm_campaign=tpp-congress-2026&utm_content=card-front
```

### Статья на VC.ru или Habr

## Что НЕ нужно делать

1. **Не добавляй UTM-метки на внутренние ссылки сайта.** Это сбивает
   реальный источник: пользователь зашёл из Яндекса, кликнул на наш
   баннер — Метрика подумает, что он из баннера, а не из Яндекса.

2. **Не используй пробелы в значениях.** `utm_campaign=Май 2026` —
   Метрика разобьёт это на две строки. Пиши `utm_campaign=may-2026`.

3. **Не используй кириллицу в значениях.** Хоть Метрика её и понимает,
   некоторые сторонние сервисы (Bitly, Sender, Mailchimp) ломают
   ссылки с не-ASCII символами.

4. **Не меняй значения «на лету».** Один источник = одно значение.
   Сегодня `utm_source=telegram`, завтра `utm_source=tg` — данные
   разойдутся по разным строкам в Метрике, итог некорректный.

5. **Не делай UTM-метки максимально длинными.** Если URL получается
   длиннее 200 символов — Telegram и WhatsApp могут «съесть»
   часть в превью.

---

## Проверка работы

1. Прокликай ссылку с UTM в инкогнито-режиме браузера.
2. Открой Метрику → отчёт «Источники» → «Метки UTM».
3. Должен появиться твой `utm_source` со счётчиком переходов.
4. Если оставил заявку — в Telegram-бот / email придёт сообщение, где
   в скрытых полях будут `utm_source`, `utm_medium`, `utm_campaign`,
   `utm_content`, `utm_term`, `sourcePath`, `referrer`.

## Шорт-урл сервис (опционально, на будущее)

Длинные UTM-ссылки страшно вставлять в Telegram-посты. Можно
использовать:

- **clck.ru** — бесплатный, от Яндекса, не требует регистрации.
- **bit.ly** — бесплатный с регистрацией, удобная аналитика.
- **t.ly** — простой, без рекламы.

Не используем сторонние сокращатели для платной рекламы (Директ,
Google Ads): рекламные системы хотят чистую конечную ссылку.
